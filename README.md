# Tera Food & Supply website

Marketing site for Tera Food & Supply. Built with Astro as a static site and hosted on Netlify.

## Run it locally

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # outputs to dist/
```

## Where things live

- `src/styles/global.css`: brand colours, fonts and shared styles
- `src/layouts/Base.astro`: page shell with SEO and Open Graph tags
- `src/components/`: header, footer, and the labelled photo placeholder
- `src/pages/`: one file per page
- `public/brand/`: logo files

Anything not confirmed yet is shown as a visible `[placeholder]`.
